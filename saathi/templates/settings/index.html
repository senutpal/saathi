Calendar subscription (ICS)

Subscribe from Google, Apple or Outlook Calendar to overlay your Saathi reminders on your existing calendar.

Privacy: anyone holding this link can read your event titles and times — treat it like a password. Regenerate it if it ever leaks; the old link stops working immediately.

{{ ics_url }}

How to subscribe

  • Google Calendar (web): Settings → Add calendar → From URL. It refreshes only about once a day — changes can take up to 24 h to appear.
  • Apple Calendar: File → New Calendar Subscription (roughly hourly).
  • Outlook: Add calendar → Subscribe from web (every 1–4 h).
