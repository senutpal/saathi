# Problem Description - P08: Here I Am

Problem Statement ID: P08
Project Name: Saathi (Here I Am)

## 1. Overview

Here I Am is about a virtual friend who assists in daily life. The basic idea is to build an application that acts as a personal assistant for the user.

How it works: the user first enters general information such as age, sex, profession, hobby, education, and work details. Based on this data, the application helps the user manage daily activity, schedule, and appointments.

## 2. Key Features

### 2.1 General Information

This option takes basic input from the user. It stores personal data of the kind usually shared on social networking sites.

a) Personal Data

* Name
* Sex
* Date of birth
* Email ID
* Phone number
* Address
* Likes
* Dislikes

b) Education

* Educational background of the user.

c) Professional Information

* Name of the organization
* Designation
* Role

d) Output

* Based on the stored details, the application generates documented personal details in the form of a CV.

### 2.2 Reminder

The user can store important schedules and receive alerts for them.

a) Input

* The user enters the date, time, and a short description of the event and saves it.

b) Output

* The user can search by date and view the schedule for that date.

## 3. Advanced Features

1. Web Search: the user can search for information on the web.
2. File Repository: the user can upload files and pictures for future use and access them later.
3. Past Activity Trail: the application tracks past meeting and activity records for later review.
4. Meeting Notes: the user can write notes about a conversation or meeting, save them, and access them later.

## 4. Authentication and Multi-User Support

The application is a web application with login support for multiple users. A new user registers first and then logs in to get a separate personal space.

## 5. Project Expectation

The points above are basic guidelines. More features are expected to make the application useful and complete.

## 6. Additional Features in Saathi

Beyond the required features, Saathi implements:

* Two factor authentication with authenticator app and backup codes.
* Natural language quick add for reminders.
* Calendar sync feed in iCalendar format for external calendars.
* Habit tracking with streak counts.
* Expense ledger with category totals.
* Time capsule messages that open on a future date.
* Account backup export and import in JSON format.
* Email alerts for due reminders and a weekly digest.
